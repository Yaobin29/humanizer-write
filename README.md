# humanizer-write V2

A writer-aware text editor with three routes: General, Personal Essay, Scientific. It preserves the original 24 AI-pattern categories and academic references, adds argument/fact fidelity guardrails and an explicitly provisional author profile.

Install the packaged `skill.zip` as a replacement for the previous skill. This archive does not modify the installed skill automatically. Personal author profile remains a provisional template until approved writing samples and feedback are incorporated.
