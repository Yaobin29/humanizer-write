# Personal Essay | 个人观点文章

适用：知乎回答、公众号原创评论、科研经验随笔、AI 与知识管理议论。

## 先读思考路径，再动句子

内部标记：触发的问题 → 作者怎样定义问题 → 从哪些个人观察/具体经历进入 → 证据或逻辑的转换 → 判断与不确定性 → 开放问题（若原文有）。不强制每篇都走同一流程；文章原有顺序清楚时保持。

## 编辑原则

- 保留自然的第一人称、适度口语、疑问、犹豫和张力，不为了“整洁”将所有段落改成相同长度。
- 识别观点与事实的边界；“我觉得/我观察到/目前没有数据支持”可有信息功能，不机械删除。
- 不因为看到“不是……而是……”、三分法、金句或排比就删除。判断该结构是否承担真实辨析；重复或虚设对立时才改。
- 优先保留作者自己选的故事和类比；如果例子占篇幅却不服务论证，可建议压缩，但不要替换为编造的生活细节。
- 开头避免过度礼貌和空洞宣言；结尾可以有钩子，但只有文章内容支持、用户愿意时才加，不默认每篇预告下一篇。
- 不为了“像真人”故意制造错别字、跑题、口癖或未经授权的夸张情绪。

## 修改粒度

轻度：去套话、保留原结构。中度：改善衔接、压缩重复。深度：重组论证；仅当用户要求或原文有明显断裂时进行。任何新增事实、例子或比喻须标注为建议而非作者经历。

## 对照自检

1. 修改后作者是否仍在回答同一个问题？
2. 作者的分歧点、推导过程及保留意见是否还在？
3. 是否错将流畅当作作者风格？
4. 有没有替作者补上从未表达的立场？
