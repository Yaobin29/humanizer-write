# Author Profile | 初版、待确认

**状态：工作假设，不是固定身份画像。** 依据用户先前明确描述的写作偏好与对话中给出的文章结构概括。未经作者认可的候选特征不得用于强制模仿；不要臆造文章原句。不得自行获取私有历史资料或声称已读取所有知乎文章。

## 候选风格特征

- 先审视问题定义，可能拆分概念，如知识获取、逻辑能力、科研能力。
- 论证倾向从科研工作经验、工具使用或阅读感想切入，之后才提出更广泛判断。
- 喜欢讨论概念区分、适用边界、因果链与证据缺口；允许“我觉得”和暂时无法验证的判断。
- 偏向清晰的个人观点与适度口语表达，反感空泛 AI 套话及机械重复；对知乎短回答尤其重视阅读节奏。
- 有时希望文章末尾留下问题或与后续主题衔接；只在文章需要时采用。

这些是**待样本校准的假设**，不能把某种段落结构、口头禅或开头强加于作者。

## 样本确认流程

1. 获取作者明确认可的 5–10 篇真实文章，记录来源、文本类型、时间及作者确认情况；未获取时不要说已经训练过作者风格。
2. 从样本总结：起手方式、论证转折、句长节奏、第一人称强度、常用例子、结尾方式和绝不允许的表达。
3. 每个特征附至少两个具体样本依据，标注高/中/低置信度；受众不同则分档案。
4. 用户指出“不像我”的修改，记录不喜欢的改动、用户实际偏好的替代、适用语境。不要把一次意见泛化到所有文章。
5. 用户要求更新档案时，先展示拟改条目或提供明确的差异；只有文件写入成功才能说已更新。
