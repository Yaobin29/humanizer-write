# Content Fidelity | 硬门槛

所有模式都适用；科研模式必须检查。

## 不得新增

- 具体事实、地名、统计数字、采访、时间、软件功能、患者/细胞/实验结果、参考文献、作者个人经历，除非用户材料确实给出或另行获授权并有证据。
- 外部权威归因（“研究表明”“专家认为”）若原文缺来源，不得润色成具体却虚假的研究。
- 未证实优先权：first、novel、unprecedented 等。

## 不得改变

- 命题立场、必要前提、核心例证、对立解释、公允性限定与未验证假设。
- 数值、单位、实验条件、材料、细胞、场强、观察对象、比较组、统计方向。
- 模态与证据等级：hypothesized / designed / observed / associated / suggests / supports / demonstrates；相关不能变因果。
- 适用范围、时态和引用归属。

## 审核方法

内部制作 `原句/主张 → 新句/主张 → 状态` 对照。状态为 unchanged、clarified、compressed、reordered、added、removed、uncertain。对 added 和 removed 做重点复核；如果涉及事实、前提或证据而用户未授权，必须恢复或显式请作者判断。不得用其他维度高分抵消重大保真错误。

原稿本身可能不准确：如未经外部核查，维持其不确定性并标注需核验，不能假定正确，也不能悄悄替换。

## 失败例

原文：“更新改善了体验。” 错误编辑：“更新添加离线模式和快捷键，测试者效率提升 40%。” 正确编辑：“这次更新改善了使用体验。” 若想更具体，写“可补充实际更新内容或测试数据”。
