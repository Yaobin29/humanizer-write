# Colloquial assertion tells（中文口语断言腔）

> 本文件针对中文写作。触发场景来自用户 2026-11-06 的实际反馈：
> 「公众号文章的 AI 味越来越浓，什么"这账要算清"，"不烧心"，什么"先摆正…"」。

## 这是什么

第一代 AI 痕迹是书面套话（此外／格局／彰显／赋能），靠词表就能抓干净。
抓干净之后，模型在「写直白、说人话、少绕弯」的指令下长出了第二代补偿物：
**把判断塞进一句口语化的断言里**。短、带情绪、像在下命令、拿不出证据。

读起来像短视频旁白，不像一个人在陈述他查到的东西。词表抓不住它，因为它由常用字组成；
必须按**句式骨架**抓。

## 六类句式（目标：每篇 0 处）

| 类别 | 典型句式 | 病在哪 |
|---|---|---|
| 结算式判断 | 这账要算清 / 这笔账 / 算一笔账 / 账要算明白 | 账在哪、谁来算、算给谁看，一个都没说 |
| 心态口号 | 先摆正心态 / 摆正位置 / 端正态度 | 在教导读者，不是在陈述事实 |
| 情绪糙话 | 不烧心 / 扎心 / 破防 / 拿捏 / 上头 / 真香 / 翻篇 | 情绪顶替了证据 |
| 祈使句开头 | 说白了 / 先说 / 记住 / 别急 / 讲真 / 说人话 / 划重点 / 抄作业 | 段落开头就指挥读者 |
| 空洞断言过渡 | 说到底 / 归根到底 / 真正的问题是 / 问题的关键 / 一句话总结 | 假装总结，实际没增加信息 |
| 能力型动词套话 | 吃透 / 读懂它 / 看透 / 讲透 / 拆透 / 捋清楚 | 说"讲透了"不等于讲透 |

## 改法只有一条

**删掉断言句，换成可核查的动作、数字或结果。换不上，就说明这句本来没内容，直接删。**

| 反例 | 正例 |
|---|---|
| 这账要算清 | 三项费用加起来是 1.7 亿 |
| 做实验做到不烧心 | 三个月不用改一版配方 |
| 你要先摆正心态 | （删掉，直接接下一句事实） |
| 说白了，这是个流量生意 | 它 96% 的收入来自广告 |
| 说到底，真正的问题是产能 | 现有产线一年只能跑 8 个批次 |
| 把这条路线吃透了 | 这条路线他改了 11 版，最后卡在纯化 |
| 不过别上头 | 湿实验命中率起点仍然很低：无序靶点那一组是零命中 |

## 更根本的一条：段落首句不许是判断句

词表只能拦住已经长出来的句子。病根在段落结构：**每段第一句就下判断，第二句才补事实**。
这种段落读十段就腻，因为读者一直被结论推着走。

硬规则：**每段第一句必须是事实句** —— 有主语、有动作、有数字或时间。判断放段中或段尾，由事实自己长出来。

- 反例：`这件事的难点不在技术，在组织。后来他们发现，三个团队用的是三套实验记录模板。`
- 正例：`三个团队各用一套实验记录模板，数据合不起来。合并花掉十一个月。`

判断留在段首，等于把读者当听众。事实放段首，读者才是在跟你一起看东西。

## 边界

引用原文、论文原句、受访者原话不受此限，加引号标明出处即可。技术术语（如"算力""吞吐"）不在此列。
